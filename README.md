# PMU Lip Color Match — 초급 시술자 학습 플랫폼

> 이 프로그램은 "정답을 계산해주는 도구"가 아니라, **초급 반영구 시술자가 다양한 입술
> 케이스를 반복적으로 진단·연습하며 색상 판단력을 체계적으로 기르는 학습 시뮬레이터**입니다.
> 색채과학(ΔE2000) 계산 결과는 참고 가설이며, 진짜 기준은 동일 조명·환경에서 촬영되고
> 숙련자가 검증한 **케이스 라이브러리**입니다. 최종 시술 판단은 반드시 숙련자의 육안
> 확인을 거쳐야 합니다.

## 실행 방법

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 폴더 구조

```
app.py                 메인 앱 (5개 모드: 소개 / 학습 / 진단연습 / 샌드박스 / 케이스추가)
lip_analysis.py         색채과학 코어 (Lab 추출, ΔE2000 색상군 분류, 배합 최적화)
case_library.py         케이스 라이브러리 관리 (JSON 인덱스 + 이미지 저장)
case_library/
├── index.json          케이스 메타데이터 (최초엔 빈 배열 [])
└── images/              케이스별 사진 (before/target/mix/after)
requirements.txt
```

## 모드 설명

| 모드 | 역할 |
|---|---|
| 🏠 소개 | 프로그램 목적, 사용 순서, 현재 라이브러리 현황 |
| 📚 학습 모드 | 5개 색상군(Yellow/Gray/Red × Brown/Purple) 진단 논리·레시피 학습 + 저장된 실제 케이스 열람 |
| 🧠 진단 연습 모드 | 사진을 보고 먼저 스스로 판단 → AI(ΔE2000) 계산과 비교 → 저장된 케이스가 있으면 실제 정답까지 3단 비교 |
| 🧪 샌드박스 | 자유 분석기. 분석 결과를 바로 케이스로 저장해 라이브러리를 채워나갈 수 있음 |
| ➕ 케이스 추가 | 실제 시술 사진·레시피를 라이브러리에 축적하는 전용 폼 (환경 태그 필수) |

## 케이스 라이브러리 — 데이터 신뢰성 설계

말씀하신 "동일 조명·환경에서 촬영한 사진을 쌓아 신뢰성을 올린다"는 요구사항을 반영해,
케이스 저장 시 **환경 태그(environment_tag)**를 필수 입력으로 강제했습니다. 같은 태그를
가진 케이스들은 같은 촬영 조건으로 간주되어, 추후 이 그룹 내에서 Lab 기준값을 보정하거나
색소 DB를 실측값으로 교체하는 데 활용할 수 있습니다.

현재는 데이터가 없는 초기 단계이므로:
- 라이브러리가 비어 있어도 학습 모드·진단 연습 모드가 **내장 지식(반영구 교재 기반 5개
  색상군 체계)**으로 바로 동작합니다.
- 사진은 "시술 전(before)" 1장만 있어도 케이스 저장이 가능하도록 느슨하게 설계했습니다.
  목표색상/배합색상/시술후 사진은 점진적으로 채워나가면 됩니다.
- `verified` 플래그로 "숙련자 검수 완료" 케이스를 구분해 두었습니다 — 추후 검증된 케이스만
  "정답"으로 쓰는 구조로 확장할 수 있습니다.

## 알려진 한계 (추후 개선 포인트)

- `PIGMENT_DB`와 `REFERENCE_TONES`의 Lab 값은 색상 설명 기반 **추정치**입니다.
  분광측색계 실측 데이터로 교체하면 정확도가 크게 올라갑니다.
- 블라인드 진단 연습 모드는 현재 "색상군 선택"만 정량 비교합니다. 톤업/중화 텍스트
  자유 입력은 아직 자동 채점하지 않고 참고용으로만 표시합니다.
- 조명 편차 보정은 간이 Gray-World 방식입니다. **단색 스와치(목표색상 사진)에는 적용하지
  않도록 수정**했습니다(적용 시 색이 무채색으로 왜곡되는 버그가 있어 수정함) — 입술 접사
  사진처럼 색이 섞인 장면에만 적용됩니다.
